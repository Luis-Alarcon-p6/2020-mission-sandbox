Quick deploy checklist

  • 1. Keep this file named index.html in repo root.
  • 2. Push to your publish branch (often main).
  • 3. Enable Pages in repository settings.
  • 4. Select branch + root folder and save.
  • 5. Visit the generated *.github.io URL.
